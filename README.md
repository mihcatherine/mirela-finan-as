# Mirela Finanças — versão simples

Aplicativo financeiro em HTML/CSS/JS, pronto para publicar no GitHub Pages.

## Como usar
1. envie os arquivos deste projeto para um repositório GitHub público.
2. no GitHub, abra Settings > Pages.
3. em Build and deployment, selecione Deploy from a branch.
4. escolha `main` e `/ (root)` e salve.
5. abra o endereço gerado no celular.

## Dados
Esta versão não usa Supabase. Os dados ficam salvos no armazenamento local do navegador/aparelho. Use Configurações > exportar meus dados para manter um backup.

## Importante
Se você limpar os dados do navegador, trocar de aparelho ou usar outro navegador, os dados locais podem não aparecer. Por isso, faça backups periódicos.
