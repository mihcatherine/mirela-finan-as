# Mirela Finanças — Versão 4

Aplicativo financeiro pessoal em HTML/CSS/JS, pronto para publicar no GitHub Pages.

## Recursos
- Resumo mensal com salário, saldo projetado e economia
- Divisão do salário entre Dia 20 e 5º Dia Útil
- Lançamentos de Receitas, Despesas e Investimentos
- Cartão com limite, fatura e disponível
- Metas financeiras
- Projeção de economia
- Contas fixas mensais
- Exportação e importação de backup
- Dados salvos localmente no aparelho
- Interface responsiva para celular

## Publicação
Envie os arquivos deste projeto para um repositório público do GitHub e ative GitHub Pages usando a branch `main` e a pasta `/ (root)`.

## Privacidade
Os dados são armazenados no `localStorage` do navegador deste aparelho. Não há necessidade de Supabase ou servidor para esta versão.
